## 실행

터미널에서 이 폴더로 이동한 뒤 실행하세요.

```sh
cd "/Users/gwakda/Documents/Codex/2026-09-28/new-chat/outputs/busan-bonus"
python3 -m http.server 4173 --bind 0.0.0.0
```

컴퓨터: http://localhost:4173

아이폰: 컴퓨터와 같은 Wi-Fi에 연결하고 Safari에서 `http://컴퓨터의로컬IP:4173`을 엽니다. Mac 시스템 설정 → Wi-Fi → 연결된 네트워크의 세부사항에서 IP 주소를 확인할 수 있습니다. 서버가 켜져 있어야 합니다. 인터넷 밖으로 공개하는 배포는 하지 않았습니다. 다른 장소에서 사용하려면 정적 웹 호스팅에 이 폴더 내용을 올리면 됩니다.

`index.html`을 직접 열어도 게임은 동작하지만, 저장을 안정적으로 유지하려면 위의 HTTP 실행을 권장합니다. 저장은 브라우저·주소·기기별로 별도입니다. 시크릿 모드나 브라우저 데이터 삭제 시 저장이 사라질 수 있습니다.

## 문구 수정

**`content.js` 한 파일**에서 모든 게임 문구를 바꿉니다.

- `sea`, `harbor`, `train`, `home`: 장소별 대사.
- `rewardTitle`, `rewardName`, `ending`, `endingLine`: 보상 공개와 마지막 엔딩 문구.
- `{n}`: 진행 숫자 자리이므로 그대로 유지합니다.

수정 후 브라우저를 새로 고치세요. 별도의 문석이 사진 파일은 전달된 첨부 목록에서 확인되지 않아, UI 시안과 요청에 적힌 외형 특징을 기준으로 캐릭터를 그렸습니다. 제품 모델명·가격은 넣지 않았습니다.

## 조작

- 모바일: 방향 버튼을 누르고 있으면 이동합니다. 물건이나 인물 가까이에 가면 자동으로 조사·대화합니다. 항구에서는 ▲로 점프, ▲와 ◀/▶ 동시 사용이 가능합니다.
- 컴퓨터: 방향키 이동, ↑ 점프, A / Z / Space / Enter로 조사·대화.
- 퍼즐: 조각을 누른 다음 모양에 맞는 칸을 누르거나, 조각을 끌어 놓습니다. 틀린 칸이면 되돌아갑니다.
- 상단 소리 버튼: 음소거. 처음부터 다시: 확인 후 진행 초기화.

네 조각은 동일한 무늬의 뒷면을 사용하고 외곽 모양으로 맞춥니다. 마지막 조각 전까지 보상의 이미지·명칭은 화면에 노출되지 않습니다. 회상 장면은 제거했습니다. 다은의 대화는 분홍색, 문석의 대화는 하늘색이며 신혼집 조사창은 연한 올리브색의 사물 전용 창이며 사물 이름만 표시됩니다.

## 파일

- `index.html`: 화면 구조
- `style.css`: 모바일 배치, 굵은 테두리, 안전 영역, 픽셀 글꼴
- `content.js`: 문구 설정
- `game.js`: 미션, 저장, 조작, 효과음, 픽셀 그림
- `assets/Galmuri11.woff2`: 동봉한 한글 픽셀 글꼴
- `assets/FONT-LICENSE.txt`: Galmuri 글꼴의 SIL Open Font License

외부 CDN이나 음원 요청 없이 실행됩니다. 맵별로 밝은 장조의 32음 멜로디와 작은 반주를 브라우저가 직접 만들며, 첫 입력 이후 재생됩니다. 저장 키는 `busan-bonus-v1`이며 조각·스테이지·좌표·코인·기차 성공 횟수·열쇠·퍼즐 배치를 저장합니다.

기차는 고정 속도·고정 성공 구간의 타이밍 게임입니다. A 입력 시 화면에 보이는 바늘 위치가 오른쪽 100% 표시 구간(98~100)에 있으면 성공합니다. 바늘은 실제 누른 위치에서 멈추며 성공 결과에만 100%가 표시됩니다. 실패 횟수로 속도·성공 구간·결과를 바꾸지 않습니다. 자동 성공이나 강제 실패가 없고 두 번 성공해야 통과합니다.

한 번 탐색하며 즐기는 5~7분을 목표로 한 짧은 구성입니다. 이동·점프 숙련도와 대사를 읽는 속도에 따라 더 빨리 끝날 수 있습니다.
